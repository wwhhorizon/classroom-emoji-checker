# 沿用的要求与工作规范

## 已确认的任务口径

本项目将旧“宿修”业务整体改为实验指导书要求的课堂表情系统。旧目录 `../course-project` 和旧压缩包保留，新项目位于 `emoji-checker`，数据与运行端口独立。

从“根据课程资料推荐大作业选题”对话沿用以下偏好：

- 符合课程 PPT 和实验指导书；实现、测试、文档、数据库脚本、部署与演示配套交付。
- 四位成员：袁谦朗 PB23111711、吴卫昊 PB23111689、李阳 PB23050986、吕祖灿 PB23111729。
- 按用户后续明确要求，不填写个人分工、贡献比例或虚构成员工作记录。
- 报告使用 LaTeX，附编译后的 PDF；不设参考文献章节；源码仓库链接放在封面和部署部分。
- 课程报告使用自然、具体的中文，围绕实现和实测结果；模型局限集中在相应章节。
- 前端使用正常产品文案，保留适量中国科大高新校区元素。
- 演示为实际浏览器录制，中文解说与字幕；空记录开始，数据由实际操作产生，不预填历史、伪造趋势或分类结果。
- 保留真实 Git 记录；不代替成员编造提交历史。
