# 需求规格说明书

## 项目目标

“课间晴雨”实现《表情符号课堂情绪检查器系统》实验指导书规定的课堂反馈业务。学生选择表情记录当前课程感受，教师查看所授课堂的历史与实时汇总，管理员维护用户、课程、课堂时间及名单，按课程、班级和时间导出记录。独立 AI 服务从视频流采样，在内存中检测人脸并分类，将带置信度的匿名结果关联到课堂。

客户端采用电脑及手机浏览器。系统包含学生客户端、教师与管理员 Web 界面、分层后端、关系数据库和独立 AI 服务，表情推理由本地模型完成。

## 角色与权限

| 角色 | 操作 | 数据范围 |
|---|---|---|
| 学生 | 注册、登录、改密、查看已安排课堂、提交表情、查询个人历史 | 本人记录及被安排的课堂 |
| 教师 | 注册、登录、改密、历史查询、统计、实时看板、开启视频采样 | 本人所授课程与课堂 |
| 管理员 | 注册、登录、改密、用户管理、课程课堂维护、名单安排、查看记录、统计与 CSV 导出、审计 | 全部课堂 |
| AI 服务 | 检测与分类、提交带来源和置信度的结果 | 使用独立服务令牌，不能操作账号或管理接口 |

教师及管理员注册需要相应邀请码。学生会话令牌不能作为 AI 服务令牌使用。教师的课堂范围由后端强制检查。

## 功能与验收标准

| 编号 | 功能 | 验收标准 |
|---|---|---|
| AUTH-01 | 注册与登录 | 三类角色可注册；用户名唯一；弱密码、错误邀请码被拒绝 |
| AUTH-02 | 密码与会话 | bcrypt 加盐哈希；改密验证原密码并吊销会话；退出后会话失效 |
| AUTH-03 | 访问控制 | 学生仅本人；教师仅所授课堂；管理员接口拒绝其他角色 |
| COURSE-01 | 课程与课堂 | 课程关联教师；课堂包含起止时间、班级与教室；结束晚于开始 |
| SCHEDULE-01 | 时间名单 | 管理员为指定课堂安排学生；拒绝无效、重复或非学生账号；版本冲突返回 409 |
| EMOJI-01 | 主动反馈 | 已排课且在上课时段的学生可提交七类表情；来源固定 MANUAL |
| EMOJI-02 | 历史查询 | 分页；按课堂、课程、班级、时间与来源组合筛选；权限适用于查询全程 |
| STAT-01 | 实时看板 | 教师及管理员查看课堂分布与分钟趋势；WebSocket 更新，权限再次核对 |
| STAT-02 | 多维统计 | 按课程、班级、时间段筛选；显示来源数量、分布、趋势及课程和班级汇总 |
| CSV-01 | CSV 导出 | 管理员导出所选范围；UTF-8 BOM；公式起始符转义；保留操作审计 |
| AI-01 | 视频处理 | 摄像头或视频文件按配置采样；Haar 人脸检测及 FER+ 模型推理 |
| AI-02 | 情绪映射 | 高兴、平静、低落、惊讶、生气、害怕、厌恶七类；带模型版本和置信度 |
| AI-03 | 结果入库 | 独立令牌；关联有效课堂和时间；阈值过滤；event_id 幂等；匿名记录 |
| AI-04 | 异常与隐私 | 断线退避重试；无脸不写记录；不保存人脸图片或原始视频；退出采样停止摄像头 |
| ADMIN-01 | 用户维护 | 查看账号；启用或停用非管理员账号；停用后阻止访问 |
| ADMIN-02 | 审计 | 登录、名单、用户状态、导出等操作留有可查询记录 |

## 非功能需求

查询使用 ORM 参数绑定；写请求检查自定义头和来源；会话使用 HttpOnly Cookie；错误统一为 `code` 和 `message`；输入长度、枚举、日期、置信度和图片大小在后端验证。原始画面仅存在于浏览器及推理进程内存中。

后端区分 Controller、Service、Repository；客户端使用 Model、View、Controller 模块；AI 独立进程并以 REST 集成。接口文档由应用导出 OpenAPI，API 版本为 1.0.0。

默认初始化课程、课堂、账号和名单，表情记录从零开始。学生提交和视频推理结果进入同一课堂记录体系。教师主动开启摄像头，也可选择本地视频；课堂视频样例及来源保存在demo-assets/。

## 用例

UC-01 学生反馈：登录后选择名单内且正在进行的课堂，选择表情并提交；系统记录学生、课堂、时间和 MANUAL 来源，个人历史随即可查。

UC-02 教师看板：教师打开本人课堂看板；学生在另一会话提交后，WebSocket 更新汇总；切换课堂或离开页面时关闭旧连接和摄像头。

UC-03 名单安排：管理员新建带时间的课堂，再选定学生名单；提交版本号避免覆盖其他安排；没有被安排的学生不能向该课堂提交。

UC-04 AI 采样：管理员或任课教师开启摄像头，或运行视频采样worker；检测到的人脸经模型分类，达到阈值的结果作为AI记录入库。页面显示检测数量、保存数量和服务状态。

UC-05 统计导出：管理员按课程、班级及起止时间筛选，对照记录与图表，再导出 CSV；教师可统计本人课程，不能使用管理员导出接口。
