# 用户手册

## 打开与登录

双击项目中的“启动课堂表情系统.cmd”。首次安装依赖需要联网，模型文件已存在时直接校验。启动窗口显示本地演示密码与访问地址。打开 `http://127.0.0.1:8010`，输入账号和密码。演示账号见 README。

新同学在登录页选择注册，填写学生账号。教师和管理员注册时填写对应邀请码，由本地配置保管。登录后在账号页面修改密码；修改成功需要重新登录。

## 学生

登录学生账号后，在“我的课堂”中选择正在进行的课堂，选择符合此刻感受的表情，再提交。提交后会显示结果，可到“我的记录”查看时间、课程、表情和来源。

只有被管理员安排进课堂名单的学生才能提交，并且必须处于课堂起止时间内。找不到课堂时，先请管理员检查课程名单和时间。界面中的统计按本人记录计算。

## 教师

登录教师账号，在课堂看板中选择所授课堂，查看表情分布、记录来源及分钟变化。学生从另一浏览器提交后，看板自动更新。历史记录及统计只包含本人所授课程。

在统计页面按课程、班级和起止时间筛选。看板分别显示主动反馈、画面识别和参加学生人数，历史列表提供每条记录的来源与时间。

需要视频采样时，先选择正在进行的课堂，再主动打开摄像头并允许浏览器权限。也可选择本地视频作为采样来源。原始视频不上传保存，系统只把采样帧送入推理服务的内存，保留匿名的表情、分数和时间。停止采样或离开页面会释放摄像头。

## 管理员

“课程与课堂”中先创建课程并选择教师，再创建课堂，填写起止时间、班级和教室。打开该课堂名单，勾选有效学生后保存。并发修改导致版本冲突时，重新打开名单再安排。

“用户管理”可查看账号和启用状态，停用非管理员账号；停用后已有会话不能继续访问。恢复启用后需要重新登录。

“表情记录”和“统计分析”支持课程、班级、时间和来源筛选。导出按钮下载当前筛选范围的CSV，可用Excel直接打开。“操作记录”显示登录、名单维护、账号状态与导出等记录。

## 常见情况

| 提示或现象 | 处理 |
|---|---|
| 当前不在课堂时间内 | 管理员新建当前时段课堂并安排学生；已有反馈课堂时间不能改写 |
| 课堂列表为空 | 检查学生是否在名单，或课程教师是否为当前账号 |
| AI 模型尚未就绪 | 等待模型校验，检查8011服务窗口；按部署说明重新下载模型 |
| 未检测到人脸 | 调整距离、光线和镜头角度 |
| 检测到但没有新增记录 | 查看分数是否低于配置阈值 |
| 摄像头不能打开 | 使用 localhost 或 HTTPS，检查浏览器授权、设备占用 |
| 密码已修改或会话失效 | 使用新密码重新登录 |
| 课堂已更新 | 刷新或重新打开编辑窗口，避免覆盖新安排 |
