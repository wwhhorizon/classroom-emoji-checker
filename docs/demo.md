# 中文解说演示

演示采用真实浏览器录制，从零表情记录开始。所有学生提交、名单安排、统计和导出均来自正在运行的应用。AI使用带CONTROLLED VIDEO INPUT标记的NASA公开样图短视频，执行真实采样、检测、分类与入库。

## 分镜与解说

### 01 课堂表情管理

这是课间晴雨，一个面向课堂的表情反馈系统。学生用表情记录对课程内容的感受，教师查看所授课堂的实时变化，管理员安排课堂名单并统计导出。接下来从没有任何表情记录的环境开始，现场建立课堂、提交反馈，再运行视频表情识别。所有页面都来自正在运行的系统。

### 02 注册与三种身份

登录页保留了中国科大高新校区的校园照片。新同学可以在这里注册学生账号，填写用户名和密码。教师与管理员也能注册，需要各自的邀请码。注册完成后回到登录页。这次演示分别使用学生、教师和管理员账号，不同身份登录后，会看到与自己有关的操作入口。

### 03 课程与授课教师

先登录管理员账号。课程与课堂页面列出已有安排，我们在这里新建一门课程，命名为软件工程课堂演示，并选择授课教师。课程保存后，教师和课程建立关联。教师的数据范围也由这个关联决定，其他教师无法读取这门课程的课堂反馈。

### 04 安排课堂时间和名单

接着为这门课程安排一节课，填写计算机二三零一班、G二教学楼教室，以及当前的起止时间。保存后打开安排学生，勾选参加这节课的两位同学。名单属于这一次课堂和具体时段。学生只有被安排进课堂，并且在课堂进行期间，才能发送表情。

### 05 学生主动反馈

现在切换到学生账号，选择刚才安排的课堂。页面上有开心、平静、低落、惊讶、生气、紧张和厌恶七种表情。选择开心以后，按钮显示当前选择，再点击发送。提交成功后，最近记录立即出现课程、班级、表情和时间。这条数据的来源是学生主动反馈。

### 06 个人历史与第二位学生

同一位学生可以在课堂不同阶段再次反馈，这里再发送一次惊讶。然后登录另一位学生，选择平静并发送。在我的记录中，第二位学生只能看到自己的一条反馈；第一位学生的记录不会出现。历史还可以按课程、课堂、时间和来源查找。

### 07 教师实时课堂看板

教师打开刚才的课堂，看板已经收到三条反馈。上方区分记录总数、参与学生、主动反馈和画面识别，下方是分布和分钟趋势。此时让学生再发送一次低落，教师页面不做刷新，数量自动变为四条。这是实时连接收到的更新，趋势里的时间点来自实际提交时间。

### 08 课程班级与时间筛选

管理员进入统计分析，选择这门课程，填写班级和时间范围，再应用筛选。当前范围内有四条主动反馈，来自两名学生。表情分布、课程汇总和班级汇总使用同一批记录。只有一个分钟出现数据时，趋势显示一个实际点，不额外填入并不存在的历史曲线。

### 09 本地视频真实推理

接下来运行视频表情识别。这里选用公开的人脸样图制成的受控短视频，画面上有明确标记，用来检查视频采样链路。浏览器实际播放视频，按间隔抽帧；独立服务检测人脸，再由本地表情模型计算类别和置信度。达到阈值的结果以匿名记录写入当前课堂，原始画面不保存。

### 10 核对画面识别记录

视频播放结束后，查看表情记录并将来源筛选为画面识别。现在可以看到刚才产生的结果、采样时间和置信度。学生姓名位置显示课堂画面，因为系统没有进行身份识别。这些数量表示采样观测次数，同一个人在多次采样中可能重复出现，因此不计入参与学生人数。

### 11 筛选结果导出CSV

回到管理员统计页面，选择刚才的课程和班级，再导出当前筛选结果。下载的文件可以直接用表格软件打开，包含表情、来源、置信度和采样时间。导出内容与当前查询范围一致。教师可以查看自己的统计，但管理员导出接口仍然由后端单独检查权限。

### 12 用户管理与操作记录

用户管理可以查看账号身份和使用状态。管理员在这里停用或恢复普通账号，停用后已登录的会话也会失效。操作记录保存登录、创建课堂、安排名单、表情入库和导出等事件。通过这些记录，可以核对刚才演示中的操作顺序和数据来源。

### 13 账号设置与工程交付

最后查看账号设置，用户可以验证原密码并设置新密码，保存后重新登录。接口文档也由实际后端生成，列出了认证、课堂、表情、统计和独立人工智能服务接口。项目同时提供需求、设计、数据库脚本、测试、部署说明、用户手册和实验报告，完整覆盖课堂表情管理的提交内容。

## 复现

先安装 `requirements-video.txt` 并运行 `python -m playwright install chromium`，启动8011独立AI服务，再准备素材、排练、录制：

```powershell
python -m ai_service.verify_pipeline --prepare-only
python scripts/record_demo.py --dry-run
python scripts/record_demo.py
```

脚本在8023创建隔离后端和新的数据库，不修改日常数据。录制环境包含基础账号和课程，但没有预填表情；演示课堂、名单和反馈通过浏览器建立。中文语音为合成配音，字幕按实际语音时间生成。`deliverables/demo-source/`包含分镜录屏、配音、字幕和MANIFEST，可用于重新剪辑。最终视频为H.264/AAC MP4，要求5～8分钟，完成后校验全片解码。
