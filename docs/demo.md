# 中文解说演示

## 课堂安排

课程为“软件工程实践 · 需求分析与用例建模”，班级为计算机2301，教室为高新校区G2-B403。丁老师授课，袁谦朗、吴卫昊、李阳、吕祖灿四位同学参加。

| 课堂环节 | 演示操作 |
|---|---|
| 课前安排 | 吕祖灿注册；管理员建立课程、安排时段并保存四人名单 |
| 概念讲解 | 袁谦朗提交开心 |
| 案例讨论 | 吴卫昊提交惊讶、李阳提交平静；查看各自历史 |
| 随堂练习 | 吕祖灿提交低落；丁老师查看实时看板 |
| 课后统计 | 按课程、班级、时间筛选；视频采样；导出CSV |
| 账号维护 | 停用与恢复账号；修改密码后重新登录 |

视频输入为 `demo-assets/classroom-expressions.mp4`，包含四个课堂环节，共32秒。素材来源和许可见 `demo-assets/ATTRIBUTION.md`。

## 录制与复现

```powershell
python -m pip install -r requirements-video.txt
python -m playwright install chromium
python scripts/build_classroom_sample.py
python scripts/record_demo.py --dry-run
python scripts/record_demo.py
```

先运行8011推理服务。录制脚本在8023启动后端，创建演示账号，再依次执行注册、排课、反馈、采样和导出。配音、字幕、分镜和CSV保存在 `deliverables/demo-source/`。

使用本机Edge录制时，在PowerShell设置 `$env:DEMO_BROWSER_CHANNEL='msedge'`，并执行 `python -m playwright install ffmpeg` 安装录屏编码工具。

## 分镜与解说

### 01 课堂表情管理

大家好，下面演示课间晴雨课堂表情管理系统。本节软件工程实践课的主题是需求分析与用例建模，由丁老师授课，袁谦朗、吴卫昊、李阳和吕祖灿四位同学参加。接下来按照课前安排、课堂反馈和课后统计的顺序，介绍学生、教师和管理员的主要操作。

### 02 学生注册

首先为吕祖灿注册学生账号。在登录页点击注册，填写用户名和密码，选择学生身份，提交后就可以登录。教师和管理员也有对应的注册入口，填写身份邀请码即可创建账号。注册完成后，我们切换到教学管理员，开始安排这节课。

### 03 建立课程

管理员进入课程与课堂，点击新建课程，填写软件工程实践，需求分析与用例建模，并选择丁老师作为授课教师。保存后，课程显示在已开课程列表中。每门课程都关联授课教师，教师登录后可以查看自己的课程、课堂记录和统计结果。

### 04 安排课堂和学生

接着点击安排课堂，选择刚建立的课程，填写计算机二三零一班、高新校区G二教学楼B四零三教室，以及本次课堂的起止时间。保存后打开学生名单，选中袁谦朗、吴卫昊、李阳和吕祖灿四位同学。名单保存后，四位同学就能在课堂时段内提交表情。

### 05 学生发送表情

现在使用袁谦朗的账号进入我的课堂。页面上方显示课程、班级、教室和丁老师的姓名，下方提供开心、平静、低落、惊讶、生气、紧张和反感七种表情。概念讲解结束后，袁谦朗选择开心并点击发送，最近的课堂记录随即出现这条反馈。

### 06 查看个人历史

案例讨论环节，吴卫昊选择惊讶并发送，然后进入我的记录，查看课程、表情、来源和提交时间。接着切换到李阳的账号，选择平静并发送。李阳的个人历史显示自己的反馈，也可以按课程、课堂和时间查找之前的记录。

### 07 教师实时看板

丁老师进入课堂看板，可以看到三位同学已经提交的三条反馈。随堂练习时，吕祖灿再发送一次低落，教师看板自动更新为四条记录，参与学生也变为四人。表情分布展示各类反馈的数量与比例，右侧趋势图展示课堂反馈随时间的变化。

### 08 多维统计

管理员进入统计分析，选择需求分析与用例建模这门课，填写计算机二三零一班和本次课堂的时间范围，再点击应用筛选。页面汇总四位同学的反馈，同时展示表情分布、时间趋势、课程统计和班级统计。切换条件后，各项图表会一起更新。

### 09 视频表情识别

教师在课堂看板中可以开启摄像头，也可以选择本地视频进行采样。这里加载课堂视频，依次展示课前准备、概念讲解、案例讨论和随堂练习。系统按设定间隔抽取画面，检测人脸并进行表情分类，达到置信度阈值的结果会保存到当前课堂。

### 10 查看识别记录

采样完成后，进入表情记录，将来源选为画面识别。列表显示每条识别结果的表情、所属课堂、置信度和采样时间，学生栏显示课堂画面。教师可以在这里回看采样结果，也可以切换到主动反馈，查看同学们发送的表情。

### 11 导出课堂数据

管理员选中本次课程和班级，点击导出CSV。下载文件包含学生姓名、课程、班级、表情、来源、置信度和记录时间，可直接用表格软件打开。导出沿用当前页面的筛选条件，便于整理一节课、一个班级或一段时间内的反馈。

### 12 用户管理和操作记录

用户管理页面列出四位同学、丁老师和教学管理员的账号信息。管理员可以查看身份和账号状态，这里演示将吕祖灿的账号停用后再恢复。随后进入操作记录，查看注册、登录、安排课堂、更新名单、提交表情和导出数据等操作。

### 13 修改密码和接口文档

最后使用吕祖灿的账号打开账号设置，填写原密码、新密码和确认密码，保存后使用新密码重新登录。系统的接口文档列出了账号、课程、课堂、表情和统计等接口。以上就是课间晴雨的主要操作，项目还附有需求设计、数据库脚本、测试报告、部署说明和用户手册。
