# 界面设计与交互说明

课间晴雨采用浏览器客户端，电脑与手机共用同一套接口。进入系统后按学生、教师与管理员的身份提供对应工作区。中文使用系统雅黑或苹方，主体为蓝白教学界面，表情选择是学生页面的主要视觉元素。

## 页面与操作

| 页面 | 使用者 | 主要操作 |
|---|---|---|
| 登录与注册 | 全部用户 | 登录，选择学生、教师或管理员身份注册；教师与管理员填写邀请码 |
| 我的课堂 | 学生 | 在已安排的课堂中选择七类表情之一并发送；查看近期个人记录 |
| 课堂看板 | 教师、管理员 | 选择课堂，实时查看表情分布、分钟趋势、主动反馈和画面识别数量 |
| 表情记录 | 全部用户 | 查看权限范围内记录，按课程、课堂、班级、时间与来源筛选 |
| 统计分析 | 全部用户 | 查看权限范围内的表情分布、分钟趋势、课程与班级统计；管理员导出CSV |
| 课程与课堂 | 管理员 | 新建课程，安排或编辑课堂，维护每节课堂的学生名单 |
| 用户管理 | 管理员 | 查看用户，启用和停用学生或教师账号 |
| 操作记录 | 管理员 | 查看最近的登录、课堂、表情及导出记录 |
| 账号设置 | 全部用户 | 校验当前密码，修改密码后重新登录 |

学生端只呈现个人记录；教师端按自己授课的课程读取；管理员可查看全部数据。菜单与请求分别承担引导和权限校验，权限由后端执行。

## 七类表情

表情类型为开心、平静、低落、惊讶、生气、紧张与反感，分别对应happy、neutral、sad、surprised、angry、fearful、disgusted。选择后显示选中边框和说明，点击“发送表情”保存。课堂尚未开始或已经结束时选择按钮禁用，页面提示可发送的时间。

## 看板与统计

数字带展示表情记录、参与学生、主动反馈与画面识别。分布条形图显示类别数量及占比；趋势图按一分钟聚合反馈数量。管理员和教师的课堂看板通过WebSocket更新，不影响正在播放的本地视频。筛选页面的列表、统计与导出使用相同筛选字段；日期时间在浏览器中转换为UTC提交。

没有记录时数量为零，趋势显示等待反馈。初始化数据不会生成表情记录。课程、课堂、用户与图表全部来自接口。

## 摄像头与本地视频

教师或管理员可以主动选择“开启摄像头”或“选择本地视频”。摄像头需浏览器授权；本地视频使用浏览器临时地址播放，页面明显显示视频文件名。采样帧在内存中缩放到最长960像素、编码为JPEG，再通过当前课堂的帧接口识别；完整视频文件不上传。

采样间隔读取服务配置。界面显示检测人脸数、保存条数与最近一次结果。无脸、低置信度、服务不可用等情况通过采样状态解释；停止后最近一次采样结果仍可查看。停止采样、离开页面、切换课堂或隐藏浏览器标签时释放摄像头和本地视频地址。

## 适配与可访问性

桌面使用固定侧栏和自适应工作区。390像素手机界面改为横向导航、单列图表与4加3的表情网格，表格可横向滚动。表单提供可见标签，表情按钮使用aria-pressed说明选中状态，实时提示通过aria-live播报，键盘焦点保持可见；减少动画偏好会关闭动画。

对话框采用原生dialog，支持关闭按钮、取消、Escape和点击外侧关闭。名单选择支持单选和全选；保存提交版本号，由后端检查冲突。

## 浏览器验证

2026年11月12日，使用真实后端接口在Chromium中检查学生、教师与管理员三类账号。桌面1440像素和手机390像素截图已核查；三类首页均无页面横向溢出。历史、统计与账号设置均可打开；管理员另检查课堂、用户及操作记录页面和课程、名单对话框。该批检查未出现JavaScript页面错误。

视频样例采用统一课堂编排：课前准备、概念讲解、案例讨论、随堂练习。CREMA-D授权动态人物素材合成在绘制教室中，并明确标注课堂场景模拟。课程、班级、人物账号、视频配色与系统一致；人物表情不预设为模型识别结果。浏览器播放本地视频并在内存抽帧，真实结果写入课堂，统计随WebSocket更新。完整录制核对全部采样与导出数量，记录见demo-verification.json；该过程不用于估计真实课堂准确率。

## 自动化操作定位

| 操作 | 稳定定位 |
|---|---|
| 登录与注册 | #login-form、#register-form、#auth-submit、#show-login、#show-register |
| 主导航 | #nav-home、#nav-history、#nav-stats、#nav-sessions、#nav-users、#nav-audit、#nav-settings |
| 选择课堂与表情 | #session-select、[data-emoji=happy]等、#send-emoji |
| 课堂数字 | [data-stat=total]、[data-stat=manual]、[data-stat=ai]、[data-stat=participants] |
| 创建课程与课堂 | #new-course、#course-form、#new-session、#session-form |
| 安排名单 | [data-schedule]、#schedule-form、[name=user_ids]、#select-all-students |
| 筛选与导出 | #filters-form、#reset-filters、#export-csv |
| 摄像头或本地视频 | #camera-start、#local-video-file、#camera-video、#sampling-source、#camera-stop |
| 采样结果 | #camera-status、#camera-result、#sampling-last-result |
| 修改密码 | #password-form |
